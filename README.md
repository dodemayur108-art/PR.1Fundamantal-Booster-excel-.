# 📊 PR. 1: Fundamental Booster (Excel Mastery)

Welcome to the **Fundamental Booster** project! This repository contains a comprehensive guide and structured tasks designed to master core-to-advanced Microsoft Excel functions, data manipulation techniques, dynamic lookups, and reporting logic. 🚀

---

## 📌 Project Overview

This project focuses on practical applications of Excel functions across different real-world scenarios such as grade classification, sales dynamic analysis, employee management, and text manipulation.

---

## 🧠 Key Topics Covered

- 📍 **Cell References & Formatting:** Relative & Absolute References (`$A$1`), Data Entry & Formatting (Bold, Italic, Currency, Date).
- 🔀 **Logical Functions:** `IF`, Nested `IF`, `IF` combined with `AND` / `OR`.
- 🔢 **Aggregate Functions:** `COUNTIFS`, `SUMIFS`, `AVERAGEIFS`.
- 🔎 **Lookup Functions:** `VLOOKUP`, `XLOOKUP`, `XMATCH`.
- 🎯 **Dynamic Searches:** `INDEX` & `MATCH` Functions.
- 🔤 **Text Manipulation:** `LEFT`, `FIND`, `UPPER`, `LOWER`.
- 🔄 **Dynamic Ranges:** `INDIRECT` & `OFFSET`.
- 📅 **Date & Math:** Date/Time functions, `ROUND`, `CEILING`, `FLOOR`.
- 📊 **Modern Excel Functions:** `FILTER` (Dynamic Array Function).

---

## 📋 Essential Tasks & Formula Breakdown

### 1. Cell References & Formatting 📌
* Input and format raw data into dates, currencies, and custom formats.
* Implement **Absolute References (`$A$1`)** and **Relative References (`A1`)** in formulas.

### 2. Logical IF & Nested IF Logic 🔀
* **Student Grade Classification:** Categorize student grades based on performance scores.
* **Discount Calculation:** Compute tiered sales discounts based on price thresholds.

### 3. IF with AND / OR Logic 🧩
* Identify students scoring above 80 in both Math and Science using `IF(AND(...))`.
* Determine product discount eligibility using `IF(OR(...))`.

### 4. Advanced Aggregations 🔢
* **`COUNTIFS`:** Count the number of students scoring above 50 in Math.
* **`SUMIFS`:** Calculate total sales for specific regions and product lines.
* **`AVERAGEIFS`:** Compute the average score for students scoring above 60.

### 5. Lookup & Search Functions 🔍
* **`VLOOKUP`:** Fetch student names based on ID or retrieve product prices by product codes.
* **`INDEX` & `MATCH`:** Dynamically look up employee details and monthly sales without column index restrictions.
* **`XLOOKUP`:** Perform flexible searches for sales performance and employee salaries.
* **`XMATCH`:** Identify the relative position of items in a product sales list.

### 6. Text Functions ✂️
* Extract first names from full names using `LEFT` and `FIND`.
* Standardize string cases using `UPPER()` and `LOWER()`.

### 7. Dynamic Reference & Ranges 🔄
* Reference cell ranges dynamically using `INDIRECT()`.
* Create dynamic range selection for sales trends using `OFFSET()`.

### 8. Date & Math Functions 📅 ➕
* Calculate exact age from Date of Birth (DOB) and evaluate day differences between dates.
* Perform financial rounding using `ROUND()`, `CEILING()`, and `FLOOR()`.

### 9. Dynamic Array Filtering 🎯
* Extract top-performing students dynamically using the `FILTER` function.
